# The Internet (herokuapp.com)

План проверок для внешнего демо-приложения The Internet.

## Общие условия

- База: `https://the-internet.herokuapp.com`
- Браузер: Chromium (headless)
- Изоляция: каждая проверка в отдельном файле
- Seed: `tests/seed.spec.ts`

---

## 1. Окна

### HEROKUAPP-001. Открытие новой страницы

**Steps:**

1. Открыть `/windows`.
2. Кликнуть ссылку «Click Here».
3. Проверить что новое окно открылось с ожидаемым URL и заголовком.

**Expected:**

- Новое окно открылось.
- URL нового окна содержит «new» и «window».
- Заголовок на новой странице — «New Window».

---

## 2. Наведение мыши

### HEROKUAPP-002. Наведение на картинку и клик по ссылке

**Steps:**

1. Открыть `/hovers`.
2. Навести на первую картинку (`.figure`).
3. Кликнуть по появившейся ссылке.
4. Проверить что страница изменилась.

**Expected:**

- После hover ссылка стала видимой.
- Клик по ссылке навигировал на новую страницу.

---

## 3. Клавиши

### HEROKUAPP-003. Нажатие клавиши Control

**Steps:**

1. Открыть `/key_presses`.
2. Сфокусировать на поле ввода.
3. Нажать клавишу Control.
4. Проверить результат.

**Expected:**

- В области результата отображается «You entered: CONTROL».

---

## 4. Drag & Drop

### HEROKUAPP-004. Перетаскивание блоков

**Steps:**

1. Открыть `/drag_and_drop`.
2. Запомнить содержимое обоих блоков.
3. Перетащить `#column-a` на `#column-b`.
4. Проверить что блоки поменялись местами.

**Expected:**

- Содержимое `#column-a` и `#column-b` поменялось местами.

---

## 5. Загрузка файлов

### HEROKUAPP-005. Загрузка файла

**Steps:**

1. Открыть `/upload`.
2. Создать временный тестовый файл.
3. Загрузить файл через input.
4. Нажать кнопку «Upload».
5. Удалить временный файл.

**Expected:**

- Отображается сообщение о успешной загрузке.

---

## 6. JavaScript alerts

### HEROKUAPP-006. Обработка JS confirm

**Steps:**

1. Открыть `/javascript_alerts`.
2. Зарегистрировать обработчик диалога (accept).
3. Кликнуть кнопку «Click for JS Confirm».
4. Проверить результат.

**Expected:**

- Диалог подтверждён.
- В области результата отображается «You clicked: Ok».
